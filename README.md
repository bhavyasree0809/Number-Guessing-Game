Number Guessing Game 🎯

📌 Project Description

The Number Guessing Game is a simple Python-based game in which the computer selects a random number, and the player tries to guess it. After each guess, the program provides hints to help the player find the correct number.

✨ Features

- 🎲 Generates a random number.
- 🔢 Allows the player to enter guesses.
- 📈 Displays hints such as "Too high!" or "Too low!"
- 🎉 Congratulates the player when the correct number is guessed.
- 🔁 Allows multiple attempts until the correct answer is found.
- 🧠 Improves logical thinking and problem-solving skills.

🛠️ Technologies Used

- Python 3
- "random" module

▶️ How to Run

1. Install Python 3.
2. Save the program as "main.py".
3. Run the program using a terminal or Python compiler.

python main.py

🎮 How to Play

1. Start the game.
2. The computer selects a secret number.
3. Enter your guess.
4. Follow the hints to guess higher or lower.
5. Continue until you find the correct number.

⚠️ Limitations

- The game runs in the terminal.
- The secret number is randomly generated for each game.
- Scores are not saved permanently.
